# mishas-motion · סקיל אנימציה ל־Claude

הסקיל של מישה קרץ' (Misha Graphics) לאנימציה ומושן דיזיין.
נותנים אותו ל־Claude, והוא עובד עם השיטה והטעם של מישה.

## מה הוא עושה

- מקבל קובץ עיצוב, גם PDF בלבד, ומפרק אותו לשכבות: רקע, צורות, לוגו, טקסט ופונטים.
- מציע קודם סיפור במילים, שלוש הצעות, ואתם בוחרים.
- בונה סטוריבורד בדף אינטרנט: פריים לכל רגע, תיבת הערה מתחת לכל פריים, וכפתור "שלח הערות".
  הערה כתובה פירושה לתקן. תיבה ריקה פירושה מאושר.
- מנפיש בקוד (HyperFrames), או ב־After Effects כשמבקשים.
- בודק את עצמו לפני שהוא מראה: טקסט שלא נוגע בצורות, ניגודיות, גודל טקסט, עוצמת סאונד ורגעים קפואים.
- מוזיקה וקריינות דרך ElevenLabs: קודם מחיר, ואתם בוחרים באוזן.
- עברית מימין לשמאל, גם בטקסט וגם בסדר של דברים על המסך.

## התקנה

### Claude Code (מומלץ)

Claude Code רץ על המחשב שלכם, ולכן הוא יכול לרנדר וידאו.
הוא נמצא באפליקציית Claude למחשב, בלשונית Code.

1. פותחים את הקובץ `mishas-motion.skill` כמו קובץ זיפ.
2. מעתיקים את התיקייה `mishas-motion` לתוך התיקייה:

   `~/.claude/skills/`

   ב־Windows זו התיקייה:

   `C:\Users\<השם שלכם>\.claude\skills\`

3. פותחים שיחה חדשה. הסקיל נטען לבד.

### claude.ai

הגדרות, ואז יכולות (Capabilities), ואז העלאת סקיל, ובוחרים את הקובץ `mishas-motion.skill`.
שם Claude מקבל את השיטה והכללים, אבל רינדור וידאו עובד רק ב־Claude Code.

## מה צריך במחשב

Claude מתקין את מה שחסר, ומבקש אישור לפני כל התקנה:

- Node.js, בשביל HyperFrames, הכלי שמרנדר HTML לווידאו.
- ffmpeg, בשביל וידאו וסאונד.
- Python, בשביל לפרק PDF לשכבות.

לא חובה: מנוי ElevenLabs וחיבור שלו ל־Claude (Connector), בשביל מוזיקה וקריינות.

## איך מתחילים

זורקים לשיחה קובץ PDF של עיצוב, וכותבים:

"תשתמש בסקיל mishas-motion. תעשה מהעיצוב הזה אנימציה בגודל סטורי (1080×1920). קודם תציע לי שלושה סיפורים במילים."
